# 💌 FUTURE MESSAGE CAPSULE


A time-locked message capsule built using PHP and MySQL.

## About the Project

Future Message Capsule is a web application where users can create messages for themselves or their friends and set a future date and time to unlock them.

It can be used to save personal thoughts, wishes, memories, reminders, birthday messages, or special messages that are meant to be opened in the future.



## Features

* Create personal future messages
* Create messages for friends
* Set a future unlock date and time
* Keep messages locked until the selected time
* Add sender and receiver details
* View saved message capsules
* Delete capsules
* Simple and user-friendly interface

## Technologies Used

* HTML
* CSS
* JavaScript
* PHP
* MySQL
* XAMPP

## How to Run

1. Install XAMPP.
2. Start Apache and MySQL from the XAMPP Control Panel.
3. Copy the project folder into:

```text
xampp/htdocs/
```

4. Create the required MySQL database.
5. Configure the database details in `db.php`.
6. Open the project in your browser:

```text
http://localhost/future-message-capsule/
```

## Main Files

* `index.php` – Home page
* `create.php` – Create a message capsule
* `capsules.php` – View saved capsules
* `open.php` – Open a capsule
* `save_capsule.php` – Save capsule data
* `check_unlock.php` – Check unlock time
* `delete_capsule.php` – Delete a capsule
* `db.php` – Database connection

## Purpose

The project was created to practice web development while building a meaningful application for preserving messages for the future.

Users can create capsules for themselves or for friends, making it useful for personal memories, special occasions, wishes, and future reminders.
